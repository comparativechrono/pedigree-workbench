On your own computer

The packages that run here are ordinary Python packages, so the commands and code that the workbench shows you will also work on your own computer: in a pipeline, on a server, or over many families at once.

Installing them

All of them except pedwb, the workbench's own runner, PedGen and PedInterp are on PyPI, at the same versions as here (Versions). They need Python 3.9 or later.

pip install pedigree-ga4gh studio2ga4gh ga4gh2studio studio2ped ped2studio mpedtools hponorm mondonorm phenopacket-toolkit

If you installed them before October 2026, add --upgrade to that command. The earlier releases of studio2ga4gh, ga4gh2studio and phenopacket-toolkit write or read the older forms that the workbench now upgrades.

PedNet is on PyPI too, at the same version as here, and needs NumPy and networkx, which pip installs with it. The commands for PedGen and PedInterp aren't released yet, so install those two from GitHub for now. The workbench's copies can be a little newer, built from a change that is waiting to be merged: the versions page gives the commit each was built from, and the workbench's own copies, below, are the same. PedInterp needs OpenCV, and to read the labels under the symbols, the Tesseract program (its README says how to install it).

pip install PedNet
pip install "git+https://github.com/comparativechrono/pedigree-generator" "git+https://github.com/comparativechrono/pedigree-interpreter"

Each package installs its own command: studio2ga4gh, ga4gh2studio, studio2ped, ped2studio, mpedtools, hponorm, mondonorm, phenotk, pedigree-ga4gh, pednet, pedgen and pedinterp. They take the same options as in the Terminal tab, so the commands that the Tools tab shows will work on your computer once you change the paths to those of your own files. In Python, the imports are the ones described in The packages in Python.

The workbench's own copies

You can also download the exact copies of the packages that the workbench uses, in one archive. This is handy on a computer that can't reach PyPI, and it includes the workbench's own runner, pedwb.

Download the packages (.zip, about 200 KB)
unzip pedigree-tools.zip -d pedigree-tools
export PYTHONPATH="$PWD/pedigree-tools"
python -m pedwb studio2ga4gh okafor.studio.json -t example-terms.json -d results
python -m pedwb pedigree-ga4gh validate results/okafor_ga4gh-pedigree.json

PedNet, PedGen and PedInterp, with networkx, are in a second archive, which needs NumPy, pandas, OpenCV and Pillow (pip install numpy pandas opencv-python pillow). Unzip it into the same folder.

Download PedNet, PedGen and PedInterp (.zip, about 1 MB)

python -m pedwb PROGRAM … runs any of the programs, just as the terminal here does. Most of them also run as python -m studio2ga4gh …, python -m phenopacket_toolkit … and so on. In Python, put the folder on PYTHONPATH (or in sys.path) and import the packages as usual.

What else they use

  • PyYAML is needed only for YAML files: pip install pyyaml.
  • rapidfuzz is optional (pip install rapidfuzz). If it's installed, hponorm's and mondonorm's searches of local copies of the ontologies also find names that are alike letter by letter but share no word. You don't need it for speed, and the scores are the same without it.
  • rich, if it's installed, gives hponorm and mondonorm their coloured questions.

Apart from these, and what PedNet, PedGen and PedInterp need (above), everything they use is part of Python's standard library. On your own computer, hponorm and mondonorm can also ask you their questions as they go, which they can't do in the terminal here.
