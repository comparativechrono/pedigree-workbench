On your own computer

The packages that run here are ordinary Python packages, so the commands and code the workbench shows run on your own computer too – in a pipeline, on a server, on many families at once.

The workbench's versions

All the packages here but mpedtools are newer than their releases on PyPI, and one, pedigree-ga4gh, is not on PyPI yet (Versions). Until they are released, use the workbench's own copies: they are in one archive, which needs only Python 3.9 or later.

Download the packages (.zip, about 190 KB)
unzip pedigree-tools.zip -d pedigree-tools
export PYTHONPATH="$PWD/pedigree-tools"
python -m pedwb studio2ga4gh okafor.studio.json -t example-terms.json -d results
python -m pedwb pedigree-ga4gh validate results/okafor_ga4gh-pedigree.json

python -m pedwb PROGRAM … runs any of the programs, as the terminal here does; most also run as python -m studio2ga4gh …, python -m phenopacket_toolkit … and so on. In Python, with the folder on PYTHONPATH (or in sys.path), the imports are those of The packages in Python.

What else they use

  • PyYAML, for YAML files: pip install pyyaml.
  • rapidfuzz, if you have it, lets hponorm's and mondonorm's searches of local copies of the ontologies also find names that are alike letter by letter but share no word: pip install rapidfuzz. It is not needed for speed or for the scores, which are the same without it.
  • rich, if you have it, gives hponorm and mondonorm their coloured questions.

Everything else is in Python's standard library. On your own computer hponorm and mondonorm can ask their questions, as they are meant to.

The releases on PyPI

pip install studio2ped ped2studio mpedtools hponorm mondonorm studio2ga4gh ga4gh2studio phenopacket-toolkit

Until the new versions are released, this gives the older ones (Versions). studio2ga4gh, ga4gh2studio and phenopacket-toolkit 0.3.0 write or read the forms that the workbench now upgrades, so use the archive above for those in the meantime. Once pedigree-ga4gh and the new versions are on PyPI, pip install gives exactly what runs here.
