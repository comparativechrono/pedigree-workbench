On your own computer

The packages that run here are ordinary Python packages, so the commands and code the workbench shows you will also run on your own computer: in a pipeline, on a server, or over many families at once.

Installing them

All of them are on PyPI, at the same versions as here (Versions). They need Python 3.9 or later.

pip install pedigree-ga4gh studio2ga4gh ga4gh2studio studio2ped ped2studio mpedtools hponorm mondonorm phenopacket-toolkit

Each package installs its own command: studio2ga4gh, ga4gh2studio, studio2ped, ped2studio, mpedtools, hponorm, mondonorm, phenotk and pedigree-ga4gh. They take the same options as in the Terminal tab, so the commands that the Tools tab shows will work on your computer once you change the paths to those of your own files. In Python, the imports are the ones described in The packages in Python.

The workbench's own copies

You can also download the exact copies of the packages that the workbench uses, in one archive. This is handy on a computer that can't reach PyPI, and it includes the workbench's own runner, pedwb.

Download the packages (.zip, about 200 KB)
unzip pedigree-tools.zip -d pedigree-tools
export PYTHONPATH="$PWD/pedigree-tools"
python -m pedwb studio2ga4gh okafor.studio.json -t example-terms.json -d results
python -m pedwb pedigree-ga4gh validate results/okafor_ga4gh-pedigree.json

python -m pedwb PROGRAM … runs any of the programs, just as the terminal here does. Most of them also run as python -m studio2ga4gh …, python -m phenopacket_toolkit … and so on. In Python, put the folder on PYTHONPATH (or in sys.path) and import the packages as usual.

What else they use

  • PyYAML reads and writes YAML files: pip install pyyaml.
  • rapidfuzz is optional. If it's installed, hponorm's and mondonorm's searches of local copies of the ontologies also find names that are alike letter by letter but share no word: pip install rapidfuzz. You don't need it for speed, and the scores are the same without it.
  • rich, if it's installed, gives hponorm and mondonorm their coloured questions.

Everything else is part of Python's standard library. On your own computer, hponorm and mondonorm can also ask you their questions as they were designed to, which the terminal here can't do.
