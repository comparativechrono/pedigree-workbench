The page

The help is on the left, and the workbench, with its five tabs, is on the right.

The tabs

TabWhat it is for
StudioPedigree Studio: draw a family, open and save drawings among your files. The Studio tab
ToolsOur Python packages, with forms for conversions, ontology terms, checks, de-identification and PED files. The Tools tab
FilesYour files and the examples: look at them, edit them, upload and download. Your files
NotebookPython notebooks with the packages, for working in code. The Notebook
TerminalThe packages' commands in a Linux shell. The Terminal

All five tabs use the same files. A file that the Tools tab writes can be opened in the Studio, read in a notebook or listed in the terminal straight away.

The help

  • Search with the box at the top. Words in titles and headings count most.
  • Hide it with the button at the top left of the page, or with Ctrl+\, to give the workbench the whole window. Do the same again to bring it back. Drag the line between the help and the workbench to change their widths, or double-click it to reset them.
  • Under the search box, Help for the … tab takes you to the page about the tab you're using.
  • Buttons in the help do what they say: they open an example in the Studio, open a tool with a file already chosen, or run a command in the terminal. Code boxes have a Copy button, and a Run in the terminal or Add to notebook button.

At the top right

  • Saved in this browser shows that your files are being stored. If the browser doesn't let the page keep them (in a private window, for example), it tells you.
  • user lets you put your own name in the terminal's prompt, if you want it there. The name is kept in this browser only.
  • My files lets you download all your files as a .zip, add files or folders from your computer, or delete everything and start again.
  • Full screen.

On a phone or tablet

The workbench works on a phone, but a pedigree is easier to draw on a larger screen. On a narrow screen, the button at the top left opens the help over the workbench, and the Tools tab's list of tools is behind All tools. Pedigree Studio has its own layout for touch screens.

One tab at a time

If the workbench is open in two browser tabs at once, both keep their files in the same place, so one tab can overwrite what the other has saved. The workbench warns you when this happens, so keep to one of the tabs.
