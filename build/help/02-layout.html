The page

The help on the left, the workbench on the right, with five tabs.

The tabs

TabWhat it is for
StudioPedigree Studio: draw a family, open and save drawings among your files. The Studio tab
ToolsOur Python packages with forms: conversions, ontology terms, checks, de-identification, PED files. The Tools tab
FilesYour files and the examples: look at them, edit them, upload and download. Your files
NotebookPython notebooks with the packages, for working in code. The Notebook
TerminalThe packages' commands in a Linux shell. The Terminal

All five use the same files: a file that the Tools tab writes can be opened in Studio, read in a notebook or listed in the terminal straight away.

The help

  • Search with the box at the top: titles and headings count most.
  • Hide it with the button at the top left of the page, or Ctrl+\, to give the workbench the whole window; the same brings it back. Drag the line between the two to change their widths (double-click it to reset).
  • Under the search box, Help for the … tab leads to the page about the tab you are using.
  • Buttons in the help do what they say – open an example in Studio, open a tool with a file chosen, run a command in the terminal. Code boxes have Copy, and Run in the terminal or Add to notebook.

At the top right

  • Saved in this browser shows that your files are stored; it says so if the browser does not let the page keep them (a private window, for example).
  • user: your name in the terminal's prompt, if you want it there. It is kept in this browser only.
  • My files: download all your files as a .zip, add files or folders from your computer, or start afresh.
  • Full screen.

On a phone or tablet

The workbench works on a phone, but a pedigree is easier to draw on a larger screen. On a narrow screen the help opens over the workbench (the button at the top left) and the Tools tab's list of tools is behind All tools. Pedigree Studio has its own layout for touch screens.

One tab at a time

The workbench open in two browser tabs at once keeps its files in the same place, and one tab can overwrite what the other saved. It warns you when this happens: use one of them.
