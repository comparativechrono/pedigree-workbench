Draw a GA4GH or Phenopackets file

A GA4GH Pedigree or a Phenopackets Family drawn in Pedigree Studio, with each condition in the colour key under its term. The drawing can be changed and converted back, and the terms come back with it.

1 · Add the file

Add it with My files → Add files from my computer…, or with From my computer… under the file box of the tool. The workbench tells GA4GH files apart by what is in them, whatever they are called. If it shows a file as plain JSON, it does not recognise it as a GA4GH file; Upgrade a file from an older tool may still be able to read it.

2 · If it was made by an older tool, upgrade it

Files made by studio2ga4gh 0.3 or abusua2ga4gh 0.2 are not in the standard form, and the tools refuse them with a message that says so. Upgrade a file from an older tool rewrites such a file once, in the standard form, and lists what it changed and anything it could not do.

The older files often name conditions without a term. The upgrade lists them; Fill in missing terms gives them their terms from a terms file (how). The drawing does not need them – a condition without a term is drawn with its name – but the GA4GH files do. A GA4GH Pedigree from studio2ga4gh 0.3 recorded only whether people were affected, not by what: draw from the Phenopackets file made with it instead, which has the conditions.

To find out whether a file needs upgrading, look at its summary in the Tools tab (the More… button beside a file): it says Older form when it does.

3 · Draw it

GA4GH or Phenopackets → drawing lays the family out from its relationships and gives each condition a colour, named in the key with its term, such as breast cancer [MONDO:0007254].

Under the result, Open the drawing in Studio shows it, laid out afresh by Pedigree Studio's Tidy if the box is ticked.

4 · Check the drawing

How much of the family comes back depends on the file:

  • From a GA4GH Pedigree: everyone, the couples (consanguineous and separated ones too), twins, adoptions, who has died, and the pregnancies and losses its narrative records.
  • From a Phenopackets Family: everyone in its pedigree, with their parents, sex and conditions. A Family's pedigree is a PED file in another form, so it has no twins and no adoptions: draw from the GA4GH Pedigree when you have one.

People are labelled with their ids, except ids that are pedigree numbers such as II-3, since Pedigree Studio numbers the generations itself. Pedigree Studio draws children from couples, so a child with only one parent in the file is given an unknown parent as the other.

The same in the terminal

pedigree-ga4gh upgrade /data/examples/older/studio2ga4gh-0.3_phenopackets-family.json -o ~/results/upgraded_phenopackets-family.json
phenotk normalise ~/results/upgraded_phenopackets-family.json --mapping /data/examples/example-terms.json --no-online -o ~/results/upgraded_phenopackets-family.json
pedigree-ga4gh validate ~/results/upgraded_phenopackets-family.json
ga4gh2studio ~/results/upgraded_phenopackets-family.json -o ~/pedigrees/upgraded.studio.json
studio --tidy ~/pedigrees/upgraded.studio.json
