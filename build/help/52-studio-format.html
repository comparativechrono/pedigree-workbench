The Pedigree Studio file

A drawing is a JSON file, and it's the same whether you save it with the Studio tab's Save or with Pedigree Studio's own File menu. It records what the drawing looks like, with its symbols, lines, positions and colours, rather than the family as data. The converters turn it into data.

What is in it

FieldWhat it holds
personsOne entry per symbol: its id, shape (male, female, unknown, their adopted forms, miscarriage for a pregnancy loss, and the no-offspring and infertile bars), position, the text under it, deceased, proband, the mark inside it (centerText: dot for a carrier, line for a presymptomatic carrier, D for a donor, S for a surrogate, P for a pregnancy, or a number when the symbol stands for several people), and how it's filled: fillMode, fillColor, halves, quarters and the shading pattern.
partnershipsThe lines between partners: the two people, and the type (normal, consanguineous, separated, consanguineous-separated).
childLinksThe lines from a couple to each child, dashed for adoption.
twinLinksTwins: the two children, and identical or nonidentical.
legendLabelsThe colour key: each colour (or pattern) and the condition's name. This is how the tools know which condition a fill means.
labels, numberingMode, …Free text placed on the drawing, how generations are numbered, and layout settings.

Personal data in a drawing

The text under the symbols is whatever was typed there, which is often names, ages and dates of birth. In a drawing made by another program, even the ids may be names, such as p-nnamdi in the examples. Treat a drawing as you would the family's notes. The GA4GH files, and the PED files from studio2ped, leave the text out and name people by pedigree numbers. But you can ask studio2ped to use the text as ids instead (Drawing → PED or MPED).
