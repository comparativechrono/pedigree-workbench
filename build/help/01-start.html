A first session

Take ten minutes to see what the workbench is for, using one of the example families. Each step has a button that does it for you.

1 · Open a drawing

The Studio tab is Pedigree Studio. Open the Okafor family, one of the examples. It has four generations, with twin boys who have had hearing loss from birth and whose parents are cousins. The twins' grandmother has had breast cancer.

The bar above the drawing says which file the drawing belongs to. The examples can't be changed, so an example opens as a new drawing that hasn't been saved yet. Change it as much as you like, then use Save as… to keep your version in ~/pedigrees. The Studio's own toolbar and its ? button explain how to draw.

2 · Give its conditions ontology terms

The colour key names two conditions. A GA4GH file names conditions by ontology terms rather than in free text: diseases by the Mondo Disease Ontology, and signs and symptoms by the Human Phenotype Ontology (HPO). The examples come with a terms file that already matches them. For a family of your own, make one with the Match conditions to terms tool (here's how).

3 · Convert it

The Tools tab has a form for each of our tools. Drawing → GA4GH Pedigree and Phenopackets writes the family as a GA4GH Pedigree and a Phenopackets Family. The button below opens the tool with the drawing and the examples' terms file (/data/examples/example-terms.json) already chosen. Then press Run. The first run starts Python in your browser, which takes a few seconds. The very first time, it also downloads about 10 MB.

Under the form, The same in the terminal, and in Python shows exactly what the tool runs: a command for the Terminal tab and code for a notebook. You can use them to do the same job again without the form.

4 · Check the result

The files it writes appear under the result, and are saved in ~/results. Press Check next to a file to check it against the standards in the same way as phenopacket-tools, the Phenopackets team's own validator. It also tells you how to fix anything that's wrong.

5 · Back to a drawing, or on to a PED file

  • GA4GH or Phenopackets → drawing draws a GA4GH file in Pedigree Studio, whether you made it here or someone has sent it to you.
  • Drawing → PED or MPED writes the PED file that linkage programs read.

6 · Keep your work

Everything you make is kept in this browser, on this computer. To keep it anywhere else, download it with a file's Download button, or with My files → Download all my files (.zip) at the top right. Your files has the details.
