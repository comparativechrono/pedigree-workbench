Turn a picture of a pedigree into a PED file and a drawing

A pedigree in a paper, a clinic letter or an old scan is only a picture. PedInterp reads one into a PED file, which the other tools can use. ped2studio then draws the PED file in Pedigree Studio, where you can check it against the picture and add what a PED file can't hold. The example is a picture of the Lynch family, drawn as pedigrees are drawn in papers.

1 · Add the picture

Add your picture with From my computer… under the file box of the tool in the next step, or with My files → Add files from my computer… at the top right. A PNG file is best. A scan or a screenshot reads better than a photograph of a page, because the drawing needs to be black on white, sharp, and square to the edges.

2 · Read it

Picture → PED file finds the symbols and the lines, works out who is whose parent, and writes the PED file. The people are numbered by generation, from the top, and from the left in each generation: I-1, I-2, II-1 and so on. The first time, Python downloads what PedInterp needs, about 21 MB, which takes a little while.

3 · Check it

The table under the result has a row for each person, with their parents (0 when they aren't in the picture), their sex (1 male, 2 female, 0 unknown), and whether they're affected (2) or not (1). Compare it with the picture. If someone is missing or has the wrong parents, When something goes wrong says what to try.

The Lynch family's PED file in the examples was made from the drawing that the picture shows, so here the two files can be compared as well: the commands at the foot of this page do it.

4 · Draw it

Under the result, Draw it (PED → drawing) opens PED or MPED → drawing with the new PED file. Run it, then open the drawing in the Studio, where Pedigree Studio's Tidy lays it out.

In the Studio, add what the picture shows but a PED file can't hold: who has died, twins, the proband, and the condition's name in the colour key. Then save the drawing. From there you can convert it to the GA4GH files, or look at the family with PedNet (Weigh up the mode of inheritance, and rank candidate variants).

The same in the terminal

pedinterp /data/examples/lynch.png --labels none -q -d ~/results
diff <(cut -f2- ~/results/lynch.ped) <(cut -f2- /data/examples/lynch.ped) && echo "the same people, parents, sexes and status"
ped2studio ~/results/lynch.ped ~/pedigrees/lynch-from-picture.studio.json
studio --tidy ~/pedigrees/lynch-from-picture.studio.json

cut -f2- leaves out the family's id, which the two files give differently.
