Put files together

This tool merges Phenopackets, Families and GA4GH Pedigrees into one Cohort or into one Family. A Cohort is a set of people who don't have to be related.

The form

The files
Add two or more files, one at a time.
Into
Choose a Cohort, such as the probands of several families, or a Family.
Its id, Save as
The new file's id, and where to save it.

Who ends up in it

  • A Cohort has every Phenopacket from every file. People are told apart by their ids, but pedigree numbers recur from family to family. So if a person's id has already been used in another file, as IV-3 might be in two families, that person is renamed after their file's id, for example FAM2-IV-3. The tool tells you who it renamed. Give each family its own id when you convert it (Family id, in Drawing → GA4GH), so that the new names show which family each person came from.
  • A Family is one family, so the same id means the same person. The first Phenopacket for each person is kept, and the tool tells you which were left out. The first person in the first file becomes the proband. The Family's pedigree comes from any Families among the files, and from the GA4GH Pedigrees' relationships. Anyone who is in neither is added as a founder, with no parents.

The new file's metaData declares every ontology that the files declare, with its release.

In the terminal

phenotk split /data/examples/okafor_ga4gh-pedigree.json --out-dir ~/results/okafor-people --affected-only
phenotk merge ~/results/okafor-people/IV-3.json ~/results/okafor-people/II-3.json --into cohort --id okafor-affected -o ~/results/okafor-affected.json
pedigree-ga4gh validate ~/results/okafor-affected.json

In Python

import phenopacket_toolkit as ptk
from phenopacket_toolkit.ops import merge

docs = [ptk.read(p) for p in ["/home/user/results/okafor-people/IV-3.json", "/home/user/results/okafor-people/II-3.json"]]
notes = []
new = merge(docs, into="cohort", cohort_id="okafor-affected", notes=notes)
ptk.write(new, "/home/user/results/okafor-affected.json")
for note in notes:
    print("note:", note)
