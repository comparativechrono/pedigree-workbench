Draw a PED file you have been sent

A PED file is hard to read as a family. Drawn in Pedigree Studio it can be checked at a glance, finished with what the PED file leaves out, and saved as a picture or converted on to the GA4GH files. The example is the PED file of the Lynch family, in which several people have had bowel or pancreatic cancer.

1 · Add the file

Add the file to your files: My files → Add files from my computer… at the top right, or From my computer… under the file box of the tool in the next step, which puts it in ~/data. The workbench knows a PED file by its ending, .ped or .fam (PLINK's name for the same six columns), and an MPED file by .mped: rename a file that ends otherwise.

2 · Draw it

PED or MPED → drawing lays the family out generation by generation and fills in the affected people (status 2). Choose the colour, and whether to fill the whole symbol or the left half, or to shade with a pattern. An MPED file's conditions each get a colour of their own.

The drawing is saved in ~/pedigrees. Open the drawing in Studio, under the result, shows it; with the box ticked, Pedigree Studio's Tidy lays it out afresh as it opens, which usually gives the neatest drawing.

3 · Finish it in the Studio

A PED file says only who the parents are, the sex and the affected status, so the drawing has only those. In the Studio you can add the rest:

  • The condition's name. The colour key calls it Affected (or, from an MPED file, by its column name). Click the key and type the condition's name, so that the drawing can be matched to terms and converted.
  • Who has died, twins, adoptions, pregnancies, a proband: select a person or a line and use the panel.
  • Labels. Each person is labelled with their id from the PED file; add ages or notes under it if you like.

Then Save in the bar above the drawing. Pedigree Studio's File menu exports a picture (PNG or SVG) to your computer.

The examples have the drawing that the Lynch PED file was made from, to compare with:

Several families in one file

A PED file can hold several families. They are all drawn, side by side, in one drawing. To draw each on its own, split the file first with One file for each family (in PED and MPED files).

The same in the terminal

mpedtools info /data/examples/lynch.ped
ped2studio /data/examples/lynch.ped ~/pedigrees/lynch.studio.json
studio --tidy ~/pedigrees/lynch.studio.json

studio opens a drawing in the Studio tab (--tidy lays it out afresh).
