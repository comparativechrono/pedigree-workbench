Compare two files

Lists what differs between two GA4GH or Phenopackets files – people, terms, relationships – leaving out the order of things and when and by whom the files were made, which change every time a file is written.

In the later version, the twins' hearing loss has been found to be sensorineural, so each has a second phenotype.

When to use it

  • To see what a conversion changed: a file and the same file converted to the other form and back.
  • To see what is new in a second version of a family's file.
  • To check that a de-identified or filtered file lost only what it should have.

Reading the result

A line for each difference, with its place in the files: proband.phenotypicFeatures: length 1 != 2, pedigree.persons[3].affectedStatus: 'UNAFFECTED' != 'MISSING' (the value in the first file, then in the second), narrative: only in A. Comparing two files of different kinds – a Family with a GA4GH Pedigree – lists nearly everything, since they are laid out differently: compare like with like. Count differences of order and of provenance too compares everything, as it is.

The exit status is 0 when the files are the same and 1 when they differ, as for diff.

In the terminal

phenotk diff /data/examples/okafor_phenopackets-family.json /data/examples/okafor-later_phenopackets-family.json
phenotk convert /data/examples/okafor_ga4gh-pedigree.json --to family -o ~/results/okafor-from-pedigree.json
phenotk diff /data/examples/okafor_phenopackets-family.json ~/results/okafor-from-pedigree.json

The second comparison shows what converting the GA4GH Pedigree to a Family loses: who was found unaffected.

--format json writes the differences as JSON; --strict is the box above.

In Python

import phenopacket_toolkit as ptk
from phenopacket_toolkit.ops import diff, render_diff

a = ptk.read("/data/examples/okafor_phenopackets-family.json")
b = ptk.read("/data/examples/okafor-later_phenopackets-family.json")
print(render_diff(diff(a, b)))
