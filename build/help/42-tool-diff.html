Compare two files

This tool lists what differs between two GA4GH or Phenopackets files, for example in their people, terms and relationships. It ignores the order of things. It also ignores when and by whom the files were made, because that changes every time a file is written.

In the later version, the twins' hearing loss has been found to be sensorineural, so each has a second phenotype.

When to use it

  • To see what a conversion changed, by comparing a file with the same file converted to the other form and back.
  • To see what's new in a second version of a family's file.
  • To check that a de-identified or filtered file lost only what it should have.

Reading the result

You'll see a line for each difference, with its place in the files, such as proband.phenotypicFeatures: length 1 != 2, pedigree.persons[3].affectedStatus: 'UNAFFECTED' != 'MISSING' or narrative: only in A. Where a line gives two values, the one from the first file comes first. If you compare two different kinds of file, for example a Family with a GA4GH Pedigree, nearly everything is listed, because they're laid out differently. So compare like with like. If you tick Count differences of order and of provenance too, the tool compares everything exactly as it's written in the files.

The exit status is 0 when the files are the same and 1 when they differ, as with diff.

In the terminal

phenotk diff /data/examples/okafor_phenopackets-family.json /data/examples/okafor-later_phenopackets-family.json
phenotk convert /data/examples/okafor_ga4gh-pedigree.json --to family -o ~/results/okafor-from-pedigree.json
phenotk diff /data/examples/okafor_phenopackets-family.json ~/results/okafor-from-pedigree.json

The second comparison shows what a Family made from the GA4GH Pedigree lacks. It doesn't say who was found to be unaffected, because the GA4GH Pedigree never recorded that.

--format json writes the differences as JSON, and --strict is the same as ticking the box above.

In Python

import phenopacket_toolkit as ptk
from phenopacket_toolkit.ops import diff, render_diff

a = ptk.read("/data/examples/okafor_phenopackets-family.json")
b = ptk.read("/data/examples/okafor-later_phenopackets-family.json")
print(render_diff(diff(a, b)))
