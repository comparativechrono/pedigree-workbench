Add findings to people

Adds diseases or phenotypes – with an age of onset, or marked as looked for and not found – or a vital status, to the proband, to everyone, or to one person, in a GA4GH or Phenopackets file. The drawing has no place for most of these; the files do.

The form

To
proband, all, affected, unaffected (as the Family's pedigree says), or one person's id, such as IV-4. Only people who have a Phenopacket in the file can be given findings.
Phenotypes, Diseases
One a line, as the term's id with its label after an equals sign: HP:0008527=Congenital sensorineural hearing impairment, MONDO:0007254=breast cancer. Find the terms with Match conditions to terms, or on the HPO's and Mondo's own sites.
These phenotypes were looked for and not found
Marks the phenotypes excluded: as useful to a diagnosis as what was found.
Age at onset
An ISO 8601 age (P45Y for 45 years, P6M for six months), for every term added.
Vital status
Alive, deceased or unknown.

A term from an ontology the file did not use yet is declared in its metaData, so the file stays valid; its release is recorded as unknown.

In the terminal, and more

phenotk add /data/examples/okafor_phenopackets-family.json --target IV-4 --phenotype "HP:0008527=Congenital sensorineural hearing impairment" --onset P0D -o ~/results/okafor-added.json
phenotk view ~/results/okafor-added.json

The command can add more than the form: a variant (--variant --gene HGNC:1884=CFTR --hgvs … --zygosity heterozygous, with --diagnosis naming the disease it explains), measurements, a cause of death, a date of birth or age, and any field by its path (--set, --merge, --append). man phenotk and phenotk add --help list them.

In Python

import phenopacket_toolkit as ptk
from phenopacket_toolkit.ops import add

doc = ptk.read("/data/examples/okafor_phenopackets-family.json")
new = add(doc, "IV-4", phenotypes=[{"id_": "HP:0008527", "label": "Congenital sensorineural hearing impairment", "onset": "P0D"}])
ptk.write(new, "/home/user/results/okafor-added.json")
