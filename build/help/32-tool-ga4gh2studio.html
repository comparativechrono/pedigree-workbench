GA4GH or Phenopackets → drawing

ga4gh2studio draws a GA4GH Pedigree or a Phenopackets Family in Pedigree Studio. Each condition gets a colour, named in the key with its term, so that the drawing converts back to the same terms.

The form

The GA4GH file
A GA4GH Pedigree or a Phenopackets Family. A file from an older tool must be upgraded first (Upgrade a file from an older tool); the tool says so if it needs to be.
Save the drawing as
A .studio.json file, in ~/pedigrees unless you choose otherwise.
Lay it out afresh with Pedigree Studio's Tidy when it opens
The tool lays the family out generation by generation; Pedigree Studio's Tidy usually makes it neater. This is done in the Studio when you open the drawing from the result, so it is not part of the command.

What comes back

  • Everyone, with their sex and whether they have died; the couples, consanguineous and separated ones too; twins; adoptions as dashed lines; donors and surrogates; pregnancies and losses, and the markers the narrative records (a carrier, for instance).
  • Each condition, coloured, and named in the key as label [ID]. A person with two conditions is filled in halves, with three or four in quarters.
  • People are labelled with their ids, except ids that are pedigree numbers (II-3), which Pedigree Studio shows itself.

A Phenopackets Family's pedigree is in the form of a PED file, so a Family gives the parents, sex and conditions, but no twins and no adoptions; a GA4GH Pedigree gives the whole family. Draw from the GA4GH Pedigree when you have one. Draw a GA4GH or Phenopackets file goes through it step by step.

In the terminal

ga4gh2studio /data/examples/okafor_ga4gh-pedigree.json -o ~/pedigrees/okafor-back.studio.json
studio --tidy ~/pedigrees/okafor-back.studio.json

Without -o, the drawing is written beside the file and named after it (okafor.studio.json for okafor_ga4gh-pedigree.json), which for an example is not possible (the examples cannot be changed). That name is often the drawing's the file was made from, which holds names and notes the file does not, so a file of that name is never replaced unless you add --force: the tool stops and says so. A file you name with -o is replaced. Version 0.3's -g FILE and -p FILE still work.

In Python

from ga4gh2studio import convert_file

result = convert_file("/data/examples/okafor_ga4gh-pedigree.json", None, "/home/user/pedigrees/okafor-back.studio.json")
print(result.summary)
for note in result.warnings:
    print("note:", note)
