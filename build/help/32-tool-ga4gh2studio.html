GA4GH or Phenopackets → drawing

ga4gh2studio draws a GA4GH Pedigree or a Phenopackets Family in Pedigree Studio. Each condition gets a colour and is named in the colour key with its term, so the drawing converts back to the same terms.

The form

The GA4GH file
Choose a GA4GH Pedigree or a Phenopackets Family. A file from an older tool must be upgraded first (Upgrade a file from an older tool), and the tool will tell you if it needs to be.
Save the drawing as
The drawing is saved as a .studio.json file, in ~/pedigrees unless you choose otherwise.
Tidy the drawing when it opens
The tool lays the family out generation by generation, and Pedigree Studio's Tidy usually makes it neater. The tidying is done in the Studio when you open the drawing from the result, so it isn't part of the command.

What comes back

  • Everyone comes back, with their sex and whether they've died. So do the couples, including consanguineous and separated ones. Twins (with ? when their zygosity isn't known), adoptions (drawn as dashed lines), donors (D), gestational carriers (G), pregnancies and losses come back too, as do the markers the narrative records, such as a carrier or a consultand. A surrogate, who gave the egg as well as carrying the pregnancy, is a genetic mother, so she's drawn as an egg donor (D), and the tool says so.
  • Each condition gets a colour, and is named in the key as label [ID]. A person with two conditions is filled in halves, and a person with three or four in quarters.
  • People are labelled with their ids, except when the ids are pedigree numbers such as II-3, because Pedigree Studio shows those itself.

A Phenopackets Family's pedigree takes the form of a PED file. So a Family gives you the parents, sex and conditions, but no twins and no adoptions, while a GA4GH Pedigree gives you the whole family. If you have a GA4GH Pedigree, draw from that. Draw a GA4GH or Phenopackets file goes through it step by step.

In the terminal

ga4gh2studio /data/examples/okafor_ga4gh-pedigree.json -o ~/pedigrees/okafor-back.studio.json
studio --tidy ~/pedigrees/okafor-back.studio.json

Without -o, the drawing is written in the same folder as the GA4GH file and named after it, for example okafor.studio.json for okafor_ga4gh-pedigree.json. That isn't possible for an example, because the examples can't be changed.

This default name is often the name of the drawing the file was made from, which may hold names and notes that the GA4GH file doesn't. So if a file of that name already exists, the tool stops and tells you, rather than replacing it. Add --force if you do want it replaced. If you name the file with -o, an existing file of that name is replaced. The -g FILE and -p FILE options from version 0.3 still work.

In Python

from ga4gh2studio import convert_file

result = convert_file("/data/examples/okafor_ga4gh-pedigree.json", None, "/home/user/pedigrees/okafor-back.studio.json")
print(result.summary)
for note in result.warnings:
    print("note:", note)
