The Terminal

The Terminal tab is a Linux-style shell, in your browser, with the pedigree programs as commands – exactly as they run on a computer where the packages are installed with pip. Every tool in the Tools tab shows its command, with a button to run it here.

The pedigree programs

CommandWhat it does
studio2ga4gha drawing → a GA4GH Pedigree and a Phenopackets Family
ga4gh2studioa GA4GH Pedigree or Phenopackets Family → a drawing
studio2ped, ped2studioa drawing → a PED or MPED file, and back
mpedtoolsPED and MPED files: info, validate, extract, merge, split, convert …
phenotkthe phenopacket toolkit: view, stats, validate, normalise, filter, deidentify, convert, upgrade, diff, split, merge, add, ped, sort
pedigree-ga4ghthe GA4GH implementation the others share: validate, upgrade, convert, kin
hponorm, mondonormmatch the names in a GA4GH file to HPO or Mondo terms (see below)
studio FILEopen a drawing in the Studio tab (--tidy lays it out afresh)

man NAME gives examples and the options; NAME --help the options alone, from the program itself. Each also runs as python -m pedwb NAME ….

cd ~/results
studio2ga4gh /data/examples/lynch.studio.json -t /data/examples/example-terms.json -d . -o lynch
pedigree-ga4gh validate lynch_ga4gh-pedigree.json
phenotk view lynch_phenopackets-family.json | grep -i cancer
ls -l

The shell

  • It is bash: pipes, redirection, variables, loops, functions, scripts (bash script.sh). ↑ and ↓ recall commands, Tab completes names, Ctrl+C stops a command.
  • The text programs – cat, head, grep, sed, cut, sort, uniq, wc, diff, column and others – are written for this terminal after the GNU ones; NAME --help says which options each has.
  • python runs Python scripts, python -c "…" and python -m json.tool FILE; pip install NAME adds pure-Python packages for this visit.
  • curl and wget download through the browser, from servers that allow web pages to (EBI, raw.githubusercontent.com); download FILE saves a file or folder to your computer.
  • Not here: programs that are not in the list (help lists them all), background jobs (&), sudo.
for f in /data/examples/*.studio.json; do
  name=$(basename "$f" .studio.json)
  studio2ga4gh "$f" -t /data/examples/example-terms.json -d ~/results/all -o "$name" --family-id "$name"
done
for f in ~/results/all/*_ga4gh-pedigree.json; do echo "$(basename "$f"): $(pedigree-ga4gh validate "$f" | tail -1)"; done

hponorm and mondonorm here

These two ask about each name as they go, waiting for an answer typed at the keyboard. This terminal cannot answer a program's questions, so they stop at the first one, keeping the choices made so far. Here they take their answers from a file instead, whose names are in lower case:

{"hearing loss from birth": {"id": "HP:0000365", "label": "Hearing impairment"}}
hponorm FILE.json --mapping answers.json --auto-remembered -o OUT.json

For most jobs, phenotk normalise FILE --mapping terms.json is simpler: it takes the workbench's terms files as they are, and fills in diseases and phenotypes in one go. To match names by pointing and clicking, use Match conditions to terms.

Keeping a session

export-session session.ipynb (or the Save session button above the terminal) saves the commands of this session, with their output, as a notebook; export-session session.sh as a script.
