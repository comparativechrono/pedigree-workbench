The Terminal

The Terminal tab is a Linux-style shell in your browser. The pedigree programs are commands in it, and they run exactly as they do on a computer where the packages have been installed with pip. Every tool in the Tools tab shows its command, with a button to run it here.

The pedigree programs

CommandWhat it does
studio2ga4gha drawing → a GA4GH Pedigree and a Phenopackets Family
ga4gh2studioa GA4GH Pedigree or Phenopackets Family → a drawing
studio2ped, ped2studioa drawing → a PED or MPED file, and back
mpedtoolsPED and MPED files: info, validate, extract, merge, split, convert …
phenotkthe phenopacket toolkit: view, stats, validate, normalise, filter, deidentify, convert, upgrade, diff, split, merge, add, ped, sort
pedigree-ga4ghthe GA4GH implementation that studio2ga4gh, ga4gh2studio and phenotk share: validate, upgrade, convert, kin
hponorm, mondonormmatch the names in a GA4GH file to HPO or Mondo terms (see below)
pedneta PED file as a graph: graph (loops, kinship, inbreeding, the closest affected relatives), mode (the mode of inheritance), rank (candidate variants by co-segregation), check
pedgensimulate a family with a dominant or recessive condition, as a PED file
pedinterpa picture of a pedigree, or a sketch of one (--hand-drawn) → a PED file, and a Pedigree Studio drawing with any twins (--studio)
studio FILEopen a drawing in the Studio tab (--tidy lays it out from scratch)

man NAME shows examples and the options, and NAME --help shows just the options, from the program itself. Each program also runs as python -m pedwb NAME …. The first time pednet, pedgen or pedinterp runs, Python downloads it, with NumPy and whatever else it needs, and says so: from about 4 MB for pednet to about 21 MB in all.

The shell

  • It's bash, so you can use pipes, redirection, variables, loops, functions and scripts (bash script.sh). ↑ and ↓ recall earlier commands, Tab completes names, and Ctrl+C stops a command.
  • The text programs – cat, head, grep, sed, cut, sort, uniq, wc, diff, column and others – were written for this terminal, modelled on the GNU ones. NAME --help tells you which options each one has.
  • python runs Python scripts, python -c "…" and python -m json.tool FILE. pip install NAME adds pure-Python packages, for this visit.
  • curl and wget download through the browser, from servers that let web pages download from them, such as EBI and raw.githubusercontent.com. download FILE saves a file or folder to your computer.
  • A few things aren't available here: programs that aren't in the list (help lists all the ones that are), background jobs with &, and sudo.
for f in /data/examples/*.studio.json; do
  name=$(basename "$f" .studio.json)
  studio2ga4gh "$f" -t /data/examples/example-terms.json -d ~/results/all -o "$name" --family-id "$name"
done
for f in ~/results/all/*_ga4gh-pedigree.json; do echo "$(basename "$f"): $(pedigree-ga4gh validate "$f" | tail -1)"; done

hponorm and mondonorm here

As they go, these two programs ask you about each name and wait for you to type an answer. This terminal can't pass your answers to a program while it's running, so they stop at the first question, keeping the choices made so far. Here, they take their answers from a file instead:

{"hearing loss from birth": {"id": "HP:0000365", "label": "Hearing impairment"}}
hponorm FILE.json --mapping answers.json --auto-remembered -o OUT.json

For most jobs, phenotk normalise FILE --mapping terms.json is simpler. It accepts the workbench's terms files unchanged, and fills in diseases and phenotypes in one go. To match names by pointing and clicking, use Match conditions to terms.

Keeping a session

export-session session.ipynb saves the commands of this session, with their output, as a notebook, and so does the Save session button above the terminal. export-session session.sh saves them as a script.
