PED or MPED → drawing

ped2studio draws a PED or MPED file in Pedigree Studio, showing the people, their parents and partners, and who is affected.

The form

The PED file
Choose a .ped, .fam or .mped file.
Save the drawing as
The drawing is saved as a .studio.json file, in ~/pedigrees unless you choose otherwise.
Colour for affected people, Fill, Shade with a pattern
These set how affected people (status 2) are marked. Choose a colour to fill the whole symbol or its left half, or use stripes or dots instead of a fill. From an MPED file, each condition gets a colour of its own.
Tidy the drawing when it opens
When you open the drawing from the result, the Studio lays it out again with Pedigree Studio's Tidy.

What comes out

The drawing shows the founders, couples and their children, generation by generation, and labels each person with their id. In the key, the condition is called Affected. From an MPED file, each condition is named after its column instead. A PED file says nothing about twins, deaths, adoptions or pregnancies, or about what the condition is. Add those in the Studio, and name the condition in the key so that it can be given a term. If one file holds several families, they're drawn side by side. Draw a PED file you have been sent goes through it step by step.

In the terminal

ped2studio /data/examples/lynch.ped ~/pedigrees/lynch.studio.json --colour '#e67e22'
studio --tidy ~/pedigrees/lynch.studio.json
Option
--colour HEX (or --color)the colour for affected people (default #1a2332)
--fill full|halfthe whole symbol, or its left half
--shading, --pattern stripes|dotsa pattern instead of a fill

In Python

from ped2studio import convert_file

session = convert_file("/data/examples/lynch.ped", "/home/user/pedigrees/lynch.studio.json",
                       affected_color="#e67e22", use_shading=False, shading_pattern="stripes", fill_type="full")
print(len(session["persons"]), "people")
