Drawing → PED or MPED

studio2ped turns a drawing into a PED file, the table of a pedigree that linkage and association programs read. If the drawing shows several conditions or carriers, it writes an MPED file instead, which has a column for each.

The form

The drawing
Choose a Pedigree Studio file, or the drawing in the Studio tab.
Save in, Start of the file name
The file is called start.ped or start.mped. It's saved in ~/results unless you choose another folder.
People are named by
Choose pedigree numbers (II-3), the labels the drawing shows, Pedigree Studio's own ids, or the text under the symbols, which is what version 0.1 used.

What it writes

The file has one line per person. Each line gives the family, the person, their father and mother, and their sex: 1 male, 2 female or 0 unknown. Then, for each condition, there's 1 for unaffected or 2 for affected, and in an MPED file 3 for a carrier.

Each condition's column is named after the condition in the colour key, so Hearing loss from birth becomes Hearing_loss_from_birth. An ontology id written after the name is left out, so Condition X [MONDO:0009061] becomes Condition_X. Only an ontology's id is left out, though. Hypertension (BP:160/95) keeps what's in its brackets, as Hypertension_BP16095. The PED and MPED formats has the details.

The father and mother are the genetic parents, because that's how linkage programs read them. An adopted child, joined to a couple by a dashed line, gets 0 in place of those parents, with a note. So does a child carried by a surrogate (a parent marked S). The Phenopackets Family's pedigree does this too. A donor (D) is a genetic parent, and is written as one.

After writing the file, the tool checks it with mpedtools and shows the result underneath.

The ids

By default, people are named by their pedigree numbers, such as II-3, as in the GA4GH files. The other choices can give you names. The text under a symbol is often a name, and a label may be one too. For example, Grace, 78 becomes Grace_78. Check these ids before you share the file. A label is made into an id by turning spaces into underscores and dropping other punctuation, so J. Mensah becomes J_Mensah. studio2ga4gh does the same, so a person has the same id in both tools' files. If two people would share an id, or an id would be empty or 0 (which a PED file reads as “no parent”), the person's pedigree number is used instead, and the tool tells you.

Pedigree Studio stores the no children and infertility bars as children of the couple. They aren't people, so the tool leaves them out, and the notes say which couple had them. Version 0.1 wrote them as children of unknown sex.

In the terminal

studio2ped /data/examples/cf-cousins.studio.json -d ~/results -o cf-cousins
mpedtools validate ~/results/cf-cousins.mped

Without -o, the file is named after the drawing, leaving out .studio.json, for example cf-cousins.mped. To use one of the other kinds of id, add --ids drawing, --ids studio or --ids text.

In Python

from studio2ped import convert_file

result = convert_file("/data/examples/cf-cousins.studio.json", output_prefix="cf-cousins", output_dir="/home/user/results")
print(result.summary)
for path, _ in result.files:
    print("wrote", path)
