Drawing → PED or MPED

studio2ped writes a drawing as a PED file, the table of a pedigree that linkage and association programs read – or, when the drawing shows several conditions or carriers, as an MPED file, which has a column for each.

The form

The drawing
A Pedigree Studio file, or the drawing in the Studio tab.
Save in, Start of the file name
The file is start.ped or start.mped, in ~/results unless you choose another folder.
People are named by
Pedigree numbers (II-3), the labels the drawing shows, Pedigree Studio's own ids, or the text under the symbols, as version 0.1 did.

What it writes

One line per person: family, person, father, mother, sex (1 male, 2 female, 0 unknown) and, for each condition, 1 unaffected, 2 affected, or 3 for a carrier in an MPED file. Each condition's column is named after it in the colour key (Hearing loss from birth becomes Hearing_loss_from_birth), without an ontology id written after it (Condition X [MONDO:0009061] becomes Condition_X). PED and MPED files has the details.

After writing, the tool checks the file with mpedtools and shows the result under it.

The ids

People are named by their pedigree numbers, II-3, as in the GA4GH files. The other choices can give names: the text under a symbol (Grace_78 for Grace, 78) often is one, and so may a label. Check those before the file leaves you. An id that two people would share, or an empty one, falls back to the person's pedigree number, and the tool says so.

The no children and infertility bars, which Pedigree Studio stores as children of the couple, are not people, so they are left out; the notes say which couple had them. (Version 0.1 wrote them as children of unknown sex.)

In the terminal

studio2ped /data/examples/cf-cousins.studio.json -d ~/results -o cf-cousins
mpedtools validate ~/results/cf-cousins.mped

Without -o, the file is named after the drawing, without .studio.json (cf-cousins.mped). --ids drawing, --ids studio or --ids text choose the other ids.

In Python

from studio2ped import convert_file

result = convert_file("/data/examples/cf-cousins.studio.json", output_prefix="cf-cousins", output_dir="/home/user/results")
print(result.summary)
for path, _ in result.files:
    print("wrote", path)
