Drawing → PED or MPED

studio2ped writes a drawing as a PED file, the table of a pedigree that linkage and association programs read – or, when the drawing shows several conditions or carriers, as an MPED file, which has a column for each.

The form

The drawing
A Pedigree Studio file, or the drawing in the Studio tab.
Save in, Start of the file name
The file is start.ped or start.mped, in ~/results unless you choose another folder.

What it writes

One line per person: family, person, father, mother, sex (1 male, 2 female, 0 unknown) and, for each condition, 1 unaffected, 2 affected, or 3 for a carrier in an MPED file. Each condition's column is named after it in the colour key (Hearing loss from birth becomes Hearing_loss_from_birth). PED and MPED files has the details.

After writing, the tool checks the file with mpedtools and shows the result under it.

Check the ids

studio2ped names each person by the text under their symbol – Grace_78 for Grace, 78 – or by Pedigree Studio's own id (p-ggf) when there is none. So the ids are often names, and two people with the same text get the same id, which makes the file invalid. Before the file leaves you, change the labels in the drawing, or make the PED file from the GA4GH files instead, which name people by pedigree number (Make a PED file for a linkage program).

The no children and infertility bars

Pedigree Studio stores these bars as children of the couple, and studio2ped writes them as children: people of unknown sex who are unaffected (m1 and m2 in the example with every kind of symbol). A linkage program would count them as real children, so delete those lines before an analysis.

In the terminal

studio2ped /data/examples/cf-cousins.studio.json -d ~/results -o cf-cousins
mpedtools validate ~/results/cf-cousins.mped

Give -o: without it, the file is named after the drawing with only .json taken off (cf-cousins.studio.mped).

In Python

from studio2ped import convert_file

result = convert_file("/data/examples/cf-cousins.studio.json", output_prefix="cf-cousins", output_dir="/home/user/results")
print(result.summary)
for path, _ in result.files:
    print("wrote", path)
