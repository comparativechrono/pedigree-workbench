Which file is which

The workbench works with a handful of kinds of file. Most of them are JSON, so their names say what they are, and the workbench also looks inside a JSON file to tell which kind it is.

KindNamedWhat it is
Pedigree Studio drawing*.studio.jsonThe drawing: every symbol, line and label, and the colour key (the format).
GA4GH Pedigree*_ga4gh-pedigree.jsonThe whole family: a Phenopacket for each person and the relationships between them (the GA4GH Pedigree).
Phenopackets Family*_phenopackets-family.jsonThe proband and relatives with findings, as Phenopackets, and a PED-style pedigree (Phenopackets).
Phenopacket, Cohort*.jsonOne person's findings; a set of Phenopackets.
PED file, MPED file*.ped, *.fam; *.mpedThe pedigree as a table for linkage programs. An MPED file has a column for each of several conditions (PED and MPED).
Terms file*-terms.jsonCondition names and their ontology terms (terms files).
Ontologyhp.obo, mondo.oboA copy of the HPO or Mondo, to search without the internet.
Other*.tsv, *.yaml, *.jsonl, *.log.jsonWhat the tools export: a table, YAML, JSON Lines, a log of decisions.

How the workbench tells them apart

The workbench looks at the name first. Then, for a JSON file, it looks at what's inside: a drawing has persons and partnerships, a GA4GH Pedigree has individuals and relationships, a Family has a proband, a Cohort has members and a Phenopacket has a subject. If the workbench doesn't recognise a file, it shows it as plain JSON or text. In the Tools tab, a file's page shows its kind, with a summary of what's in it.

Older GA4GH files

Files made by studio2ga4gh 0.3 or abusua2ga4gh 0.2 are recognised as GA4GH files, but in an older form that the standard doesn't accept. A file like this has Older form on its page, and Upgrade a file from an older tool rewrites it.
