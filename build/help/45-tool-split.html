One file for each person

Splits a Phenopackets Family, a Cohort or a GA4GH Pedigree into a Phenopacket for each person – or for each person with findings. Use it to send one person's findings without the rest of the family.

The form

The file
A GA4GH Pedigree, a Phenopackets Family or a Cohort.
Only the people with findings
Leave out the people with no disease or phenotype recorded.
Save in the folder
~/results/name-people: each file is named after its person's id, such as IV-3.json.

Each Phenopacket is complete on its own, with its metaData (taken from the file's when it has none of its own). A Phenopacket says nothing about relatives, so the family's structure stays behind – which is the point, when one person's findings are all that should go.

In the terminal

phenotk split /data/examples/okafor_ga4gh-pedigree.json --out-dir ~/results/okafor-people --affected-only
ls ~/results/okafor-people

In Python

import os
import phenopacket_toolkit as ptk
from phenopacket_toolkit.ops import split

doc = ptk.read("/data/examples/okafor_ga4gh-pedigree.json")
os.makedirs("/home/user/results/okafor-people", exist_ok=True)
for packet in split(doc, affected_only=True):
    sid = packet.proband().subject.id
    ptk.write(packet, os.path.join("/home/user/results/okafor-people", sid + ".json"))
