One file for each person

This tool splits a Phenopackets Family, a Cohort or a GA4GH Pedigree into a separate Phenopacket for each person, or for each affected person. Use it to send one person's findings without the rest of the family.

The form

The file
A GA4GH Pedigree, a Phenopackets Family or a Cohort.
Only the affected people
Tick this to make files only for the people who are affected. In a Phenopackets Family, they're the people its pedigree marks as affected. In a GA4GH Pedigree or a Cohort, they're the people with at least one disease or phenotype that is present rather than excluded.
Save in the folder
By default, this is ~/results/name-people. Each file is named after its person's id, such as IV-3.json.

Each Phenopacket is complete on its own, with its metaData. If a Phenopacket has none of its own, it gets a copy of the one in the file you split. A Phenopacket says nothing about relatives, so the family's structure stays behind. That's what you want when only one person's findings should be sent.

In the terminal

phenotk split /data/examples/okafor_ga4gh-pedigree.json --out-dir ~/results/okafor-people --affected-only
ls ~/results/okafor-people

In Python

import os
import phenopacket_toolkit as ptk
from phenopacket_toolkit.ops import split

doc = ptk.read("/data/examples/okafor_ga4gh-pedigree.json")
os.makedirs("/home/user/results/okafor-people", exist_ok=True)
for packet in split(doc, affected_only=True):
    sid = packet.proband().subject.id
    ptk.write(packet, os.path.join("/home/user/results/okafor-people", sid + ".json"))
