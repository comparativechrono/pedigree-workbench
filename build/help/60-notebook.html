The Notebook

The Notebook tab runs Python notebooks in your browser, with all the pedigree packages installed. They're the same .ipynb files that Jupyter uses. The tab is for work the forms don't cover, such as many families at once, your own checks, or a record of an analysis that can be run again.

The notebooks to start from

~/notebooks/pedigree-tools.ipynb walks you through the packages. It covers reading a drawing, converting it and checking the result, the family as Python objects, the phenopacket toolkit, PED files, and running commands from a cell. ~/notebooks/pedigree-analysis.ipynb goes on to PedNet, PedGen and PedInterp: a family as a graph, its kinship and loops, its mode of inheritance, candidate variants, simulated families, and a pedigree read from a picture. Run their cells from the top. If you've deleted one, its button here brings back a fresh copy.

Working in a notebook

  • Run a cell with Shift+Enter, or use Run all to run every cell from the top. The first cell you run starts Python, which takes a few seconds, and the very first time it also downloads about 10 MB.
  • Code and Text add cells, and text cells are written in Markdown. Use a cell's menu to move, duplicate, clear or delete it.
  • Stop stops a cell that's running for too long, and Restart forgets all the variables. The variables button lists everything the notebook has defined.
  • The notebook is saved in your files as you work. Download gives you a copy as a Jupyter notebook, a Python script, or a web page with its results.
  • As in Jupyter, a notebook starts in its own folder. It uses the same files as the other tabs: the examples in /data/examples, and your home folder, /home/user.

Commands in a cell

As in Jupyter, a line that starts with ! runs a command, and lines that start with % are the notebook's own commands:

!studio2ga4gh /data/examples/okafor.studio.json -t /data/examples/example-terms.json -d ~/results -o okafor-nb
!pedigree-ga4gh validate ~/results/okafor-nb_ga4gh-pedigree.json
!commandRuns a command, as in the Terminal tab. The pedigree programs and python run in the notebook's own Python. To use them in a pipe or with redirection (| or >), use the Terminal tab.
%cd, %pwd, %lsChange or show the folder, or list the files in it
%pip install NAMEInstalls a pure-Python package from PyPI, for this visit
%%writefile FILE, %%bash, %%capture, %time, %runWork as they do in Jupyter

The packages

These packages are installed: studio2ga4gh, ga4gh2studio, studio2ped, ped2studio, mpedtools, hponorm, mondonorm, phenopacket-toolkit and pedigree-ga4gh. PedNet (pednet), PedGen and PedInterp are loaded, with NumPy, pandas and OpenCV as they need them, when a cell first imports one of them or runs one of their commands. They're the versions that come with the workbench (Versions). PyYAML is installed too. The packages in Python shows the main functions of each one. Every tool in the Tools tab shows its Python code under The same in the terminal, and in Python, with an Add to notebook button.

One Python for three tabs

The Tools tab, the Notebook tab and the Terminal tab share one Python. While a notebook cell is running, a tool waits for it to finish, and the other way round.
