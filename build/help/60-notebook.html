The Notebook

The Notebook tab runs Python notebooks – the same .ipynb files as Jupyter – in your browser, with all the pedigree packages installed. It is for work the forms do not cover: many families at once, your own checks, a record of an analysis that can be run again.

The welcome notebook

~/notebooks/pedigree-tools.ipynb walks through the packages: reading a drawing, converting it, checking the result, the family as Python objects, the phenopacket toolkit, PED files, and commands from a cell. Run its cells from the top.

Working in a notebook

  • Run a cell with Shift+Enter; Run all runs them from the top. The first cell starts Python, which takes a few seconds (and downloads about 10 MB the first time).
  • Code and Text add cells; a text cell is Markdown. Each cell's menu moves, duplicates, clears or deletes it.
  • Stop stops a cell that runs too long, and Restart forgets the variables. The variables button lists what the notebook has defined.
  • The notebook is saved among your files as you work. Download gives it as a Jupyter notebook, a Python script, or a web page with its results.
  • A notebook starts in its own folder, as in Jupyter, and reads and writes the same files as the other tabs: /data/examples, and your home, /home/user.

Commands in a cell

As in Jupyter, a line that starts with ! runs a command, and % lines are the notebook's own commands:

!studio2ga4gh /data/examples/okafor.studio.json -t /data/examples/example-terms.json -d ~/results -o okafor-nb
!pedigree-ga4gh validate ~/results/okafor-nb_ga4gh-pedigree.json
!commanda command, as in the Terminal tab. The pedigree programs and python run in the notebook's own Python; for a pipe (|) or redirection (>) into them, use the Terminal tab
%cd, %pwd, %lschange or show the folder, list files
%pip install NAMEinstall a pure-Python package from PyPI, for this visit
%%writefile FILE, %%bash, %%capture, %time, %runas in Jupyter

The packages

studio2ga4gh, ga4gh2studio, studio2ped, ped2studio, mpedtools, hponorm, mondonorm, phenopacket_toolkit and pedigree_ga4gh are installed, in the versions the workbench carries (Versions), with PyYAML. The packages in Python shows the main functions of each. Every tool in the Tools tab shows its Python under The same in the terminal, and in Python, with Add to notebook.

One Python for three tabs

The Tools tab, the Notebook and the Terminal share one Python. While a notebook cell runs, a tool waits for it to finish, and the other way round.
