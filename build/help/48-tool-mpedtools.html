PED and MPED files

mpedtools works with PED files, and with MPED files, which are PED files with a column for each of several conditions. Its five tools in the Tools tab summarise and check a file, take one condition out, put files together, split families apart, and turn one kind of file into the other.

The five tools

Summary and check
This lists the families and the people (founders and the rest, by sex), and for each condition, how many people are affected, unaffected and carriers. Then it checks for people listed twice, parents who aren't in the file, parents of the wrong sex, and status codes other than 0, 1, 2 and 3.
Take one condition out
This makes a plain PED file for one condition of an MPED file. Give the condition's column name, as the file's first line or the summary shows it. If you leave the name empty, you get a file for each condition. Carriers (3) become unaffected (1), because a plain PED file has no code for them.
Put PED files together
This puts PED files of the same people, with one condition each, into one MPED file. Name the conditions in the same order as the files, or each one is named after its file.
One file for each family
This splits a PED or MPED file of several families into a file for each family, named after the family's id.
PED ⇄ MPED, and columns
This turns a PED file into an MPED file, or the other way round, keeping one condition. It can also add or remove a condition column. A new column starts with everyone at the value you choose.

In the terminal

mpedtools info /data/examples/cf-cousins.mped
mpedtools validate /data/examples/cf-cousins.mped
mpedtools extract-all /data/examples/okafor.mped -d ~/results -p okafor
mpedtools convert /data/examples/lynch.ped -o ~/results/lynch.mped -f mped
Command
info FILE, validate FILEthe summary; the check (exit status 1 if it finds an error)
extract FILE CONDITION -o OUT, extract-all FILE -d DIR -p STARTone condition, or each, as a plain PED file
merge A.ped B.ped … -o OUT -n NAME …PED files into one MPED file
split FILE -d DIR -p STARTa file for each family
convert FILE -o OUT -f ped|mped [--phenotype NAME]one kind into the other
add-phenotype FILE NAME -o OUT [--default N], remove-phenotype FILE NAME -o OUTadd a column, or remove one

In Python

import mpedtools

ped = mpedtools.read("/data/examples/okafor.mped")
print(mpedtools.summarise(ped))
for issue in mpedtools.validate(ped):
    print(issue.level, issue.message)
one = mpedtools.extract_phenotype(ped, "Hearing_loss_from_birth")
mpedtools.write(one, "/home/user/results/okafor_hearing.ped", force_format="ped")

The PED and MPED formats describes the columns, the codes and the MPED header.
