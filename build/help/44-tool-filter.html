Keep some people or terms

Makes a smaller file from a GA4GH or Phenopackets file: only the proband, only the affected, one sex, or the people you name – or only some terms. Use it to share no more than is needed.

The form

People, Sex, Only these people
Which people to keep: everyone, the proband, or the affected; either sex; and, if you list ids (one a line), only those.
Only these terms
Term ids (CURIEs), one a line: each person keeps only those of their terms.
Of the terms
Keep observed and excluded terms, or only those observed, or only those looked for and not found.
Reverse
Drop what matches, instead of keeping it.
Tidy the pedigree
For a Phenopackets Family: take the people left out out of its pedigree too, with every line to them, so that the file stays valid. The relatives in the pedigree who never had a Phenopacket stay. (In a GA4GH Pedigree, the relationships and index patients that name someone left out are always dropped.)

The ids you list are written to a small file beside the result (…-ids.txt), which the command reads. To send one person's findings without the rest of the family, One file for each person is the better tool: a Family always carries its pedigree.

In the terminal

phenotk filter /data/examples/okafor_ga4gh-pedigree.json --affected --prune-pedigree -o ~/results/okafor.affected.json
phenotk filter /data/examples/okafor_ga4gh-pedigree.json --term HP:0000365 -o ~/results/okafor.hearing.json
phenotk view ~/results/okafor.affected.json

Other options: --proband-only, --sex FEMALE|MALE, --id-list FILE, --observed, --excluded, --invert, and --include-descendants with a copy of the ontology (--hpo-file, --mondo-file) to keep the terms under a term as well.

In Python

import phenopacket_toolkit as ptk
from phenopacket_toolkit.ops import filter_document

doc = ptk.read("/data/examples/okafor_ga4gh-pedigree.json")
new = filter_document(doc, affected_only=True, prune_pedigree=True)
ptk.write(new, "/home/user/results/okafor.affected.json")
