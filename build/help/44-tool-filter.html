Keep some people or terms

This tool makes a smaller file from a GA4GH or Phenopackets file. It can keep only the proband, only the affected people, one sex or the people you name, or only some terms. Use it to share no more than is needed.

The form

People, Sex, Only these people
Choose which people to keep: everyone, the proband or the affected people. You can also keep only one sex. If you list ids, one per line, only those people are kept.
Only these terms
List term ids (CURIEs), one per line. Each person then keeps only those of their terms that are on the list.
Of the terms
Keep both observed and excluded terms, only the observed ones, or only the ones that were looked for and not found.
Reverse
Drop what matches, instead of keeping it.
Tidy the pedigree
For a Phenopackets Family, this also removes from its pedigree the people who've been left out, with every line to them, so that the file stays valid. Relatives in the pedigree who never had a Phenopacket stay in it. In a GA4GH Pedigree, relationships and index patients that name someone who's been left out are always dropped.

The ids you list are written to a small file next to the result (…-ids.txt), and the command reads them from there. To send one person's findings without the rest of the family, use One file for each person instead, because a Family always carries its pedigree.

In the terminal

phenotk filter /data/examples/okafor_ga4gh-pedigree.json --affected --prune-pedigree -o ~/results/okafor.affected.json
phenotk filter /data/examples/okafor_ga4gh-pedigree.json --term HP:0000365 -o ~/results/okafor.hearing.json
phenotk view ~/results/okafor.affected.json

Other options are --proband-only, --sex FEMALE|MALE, --id-list FILE, --observed, --excluded and --invert. There's also --include-descendants, which uses a copy of the ontology (--hpo-file, --mondo-file) to keep the terms under a term as well.

In Python

import phenopacket_toolkit as ptk
from phenopacket_toolkit.ops import filter_document

doc = ptk.read("/data/examples/okafor_ga4gh-pedigree.json")
new = filter_document(doc, affected_only=True, prune_pedigree=True)
ptk.write(new, "/home/user/results/okafor.affected.json")
