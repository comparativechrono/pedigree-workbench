GA4GH → PED, table or YAML

Writes a GA4GH Pedigree, a Phenopackets Family, Cohort or Phenopacket in another format: a PED file for linkage programs, a table of people and their terms, YAML, or JSON Lines.

The formats

A PED file
Six columns – family, person, father, mother, sex, affected status – with the file's ids, which are pedigree numbers (II-3) in files from studio2ga4gh. Made from a Phenopackets Family, the status is the one its pedigree records: 1 unaffected, 2 affected. Made from a GA4GH Pedigree, people with a condition are 2 and everyone else is 0, unknown, because a GA4GH Pedigree records the conditions people have, not that they were found to have none. In both, affected means having any of the file's conditions: for one condition of several, use the other route of Make a PED file for a linkage program.
A table (TSV)
A row for each person and term: the person's id, their role (proband or relative), whether the term is a disease or a phenotype, its id and label, and whether it was excluded (looked for and not found). It opens in a spreadsheet.
YAML
The same document, in YAML instead of JSON.
JSON Lines
One Phenopacket on each line, for programs that read many at a time.

In the terminal

phenotk convert /data/examples/okafor_phenopackets-family.json --to ped -o ~/results/okafor.ped
phenotk convert /data/examples/okafor_ga4gh-pedigree.json --to tsv -o ~/results/okafor.tsv
column -t -s "$(printf '\t')" ~/results/okafor.tsv

--to takes ped, tsv, yaml, jsonl and json, and family or pedigree for the other GA4GH form. phenotk ped FILE writes the PED file too.

In Python

import phenopacket_toolkit as ptk
from phenopacket_toolkit.ops import to_format

doc = ptk.read("/data/examples/okafor_phenopackets-family.json")
print(to_format(doc, "ped"))
print(to_format(doc, "tsv"))
