Versions, and how to cite

What this copy of the workbench runs. Say which versions you used when you report work done with it – the files record it too, in their metaData (createdBy: studio2ga4gh 0.4.0).

Python is Pyodide's, loaded from jsDelivr when Python first starts; python --version in the terminal, or the Python pill in the Tools tab, says which.

Newer than PyPI

All the packages here but mpedtools are newer than their releases on PyPI, and are on their way there:

  • studio2ga4gh, ga4gh2studio and phenopacket-toolkit are version 0.4.0 (0.3.0 on PyPI). They read and write GA4GH files through pedigree-ga4gh, which is new, and so write the one corrected form (The GA4GH Pedigree). The 0.4.0 toolkit also fixes faults of 0.3.0 that made some of its files invalid.
  • studio2ped is 0.2.0 (0.1.0 on PyPI). It names people by their pedigree numbers, as studio2ga4gh does, and leaves out the “no children” and “infertility” marks, which are not people.
  • ped2studio is 0.2.2 (0.2.1 on PyPI). It keeps apart families that reuse the same ids.
  • hponorm and mondonorm are 1.1.0 (1.0.0 on PyPI). They score OLS's results by how well they match, take synonyms into account, read terms files in any case, and search a local copy of an ontology much faster.
