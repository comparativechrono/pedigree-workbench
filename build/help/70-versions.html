Versions, and how to cite

These are the versions that this copy of the workbench runs. When you report work done with it, say which versions you used. The files record them too, in their metaData (for example createdBy: studio2ga4gh 0.4.0).

Python itself is Pyodide's, which is loaded from jsDelivr the first time Python starts. To see which version you have, type python --version in the terminal, or click the Python pill in the Tools tab.

The same as on PyPI

Every package here is the version that is released on PyPI, so pip install on your own computer gives you exactly the code that runs in the workbench. The releases of October 2026 brought these changes:

  • pedigree-ga4gh 1.0.0 is new. It's the one implementation of the GA4GH Pedigree and of Phenopackets that the other packages share, so they all read and write the same, corrected form (The GA4GH Pedigree).
  • studio2ga4gh, ga4gh2studio and phenopacket-toolkit 0.4.0 read and write their GA4GH files through pedigree-ga4gh. The toolkit also fixes faults in 0.3.0 that made some of its files invalid, and its normalise now fills in a term only when the name is the term's label or one of its synonyms, unless you ask it to accept closer guesses.
  • studio2ped 0.2.0 names people by their pedigree numbers, as studio2ga4gh does, and puts only genetic parents in the father and mother columns. It also leaves out the “no children” and “infertility” marks, which aren't people.
  • ped2studio 0.2.2 keeps apart families that reuse the same ids.
  • hponorm and mondonorm 1.1.0 score OLS's results by how well they match, take synonyms into account and read terms files whatever their case. They no longer treat names that are spelt alike but mean different things, such as hypothyroidism and hyperthyroidism, as close matches, and they search a local copy of an ontology much faster.

mpedtools is still at version 0.1.0. On your own computer explains how to install the packages outside the browser.
