Versions, and how to cite

What this copy of the workbench runs. Say which versions you used when you report work done with it – the files record it too, in their metaData (createdBy: studio2ga4gh 0.4.0).

Python is Pyodide's, loaded from jsDelivr when Python first starts; python --version in the terminal, or the Python pill in the Tools tab, says which.

Newer than PyPI

studio2ga4gh, ga4gh2studio and phenopacket-toolkit here are version 0.4.0, newer than their releases on PyPI (0.3.0): they read and write GA4GH files through pedigree-ga4gh, which is new, and so write the one corrected form (The GA4GH Pedigree). The 0.4.0 toolkit also fixes faults of 0.3.0 that made some of its files invalid. The other five packages are the same as on PyPI. On your own computer says how to use these versions outside the browser.
