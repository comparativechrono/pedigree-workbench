The Tools tab

The Tools tab puts our Python packages behind forms. Choose a file, set the options, press Run: the tool runs its package's command, exactly as the terminal would, and shows what it wrote. Under every form is the same command for the terminal, and the same work in Python, so that nothing the tab does is hidden.

Finding the tool you need

  • The first page has the map of the formats and the tools between them, and the common tasks with their tools in order. Click an arrow on the map to open that tool, or a box to list everything that can be done with that kind of file.
  • The list on the left (All tools on a narrow screen) has every tool, in groups.
  • From a file: More… beside a file a tool has written, the Files tab's buttons, and the Studio's Convert or check… all open the file's own page: what is in it, and the tools that read it.

A tool's page

  1. The fields. Files are chosen from your files or the examples, from your computer (From my computer…), or, for a drawing, from the Studio tab as it is now (The drawing in the Studio tab, which saves it first). Look at it opens the chosen file. Names of the files it will write are filled in for you and can be changed; results go in ~/results unless you say otherwise.
  2. Run. The first run of a visit starts Python in your browser (a few seconds; the first time, it downloads about 10 MB). If a file would be written over, you are asked first.
  3. The result: Done or the error, what the program printed, and the files it wrote, each with buttons to open it in the Studio, look at it, check it, take it to another tool, or download it.
  4. The same in the terminal, and in Python: the command and the code, with buttons to run them in the Terminal tab or add them to a notebook.

More about this tool, under the title, says what the tool does and does not do, with a link to its page in this help. At the top right, the Python pill says whether Python is running; click it for the versions of the packages.

The tools

Convert

  • Drawing → GA4GH Pedigree and Phenopackets (studio2ga4gh)
  • GA4GH or Phenopackets → drawing (ga4gh2studio)
  • Drawing → PED or MPED (studio2ped)
  • PED or MPED → drawing (ped2studio)
  • GA4GH Pedigree ⇄ Phenopackets Family (phenotk)
  • GA4GH → PED, table or YAML (phenotk)

Ontology terms

  • Match conditions to terms (hponorm and mondonorm)
  • Fill in missing terms (phenotk)

Check and look inside

  • Check against the standard (pedigree-ga4gh)
  • Upgrade a file from an older tool (pedigree-ga4gh)
  • Look inside a GA4GH file (phenotk)
  • Compare two files (phenotk)

Prepare to share

  • De-identify (phenotk)
  • Keep some people or terms (phenotk)
  • One file for each person (phenotk)
  • Put files together (phenotk)
  • Add findings to people (phenotk)

PED and MPED files

  • Summary and check, Take one condition out, Put PED files together, One file for each family, PED ⇄ MPED (mpedtools)
What the tab does not do

Each tool runs one command of one package, as it is, and the tab adds no conversions of its own. The exception is Match conditions to terms, which has no command: it searches with the packages' Python and writes a terms file. A few commands have options that the forms leave out – phenotk add's variants, for example – which man and --help describe in the terminal.
