The Tools tab

The Tools tab gives each of our Python packages a simple form. Choose a file, set any options and press Run. The tool runs exactly the command you would type in the terminal, then shows you the files it wrote. Under every form you'll find that command too, and the same job written in Python, so you can always see what the tab is doing.

Finding the tool you need

  • The first page has a map of the formats and the tools that go between them. It also lists the common tasks, each with its tools in the order you use them. Click an arrow on the map to open that tool, or click a box to list everything you can do with that kind of file.
  • The list on the left (All tools on a narrow screen) has every tool, arranged in groups.
  • From a file, you can open the file's own page, which shows what's in it and the tools that read it. Use More… next to a file that a tool has written, the buttons in the Files tab, or Convert or check… in the Studio.

A tool's page

  1. The fields. You can choose files from your files or the examples, or from your computer with From my computer…. For a drawing, you can also choose The drawing in the Studio tab, which uses the drawing that's open there and saves it first. Look at it opens the file you've chosen. The names of the files the tool will write are filled in for you, and you can change them. Results go in ~/results, drawings in ~/pedigrees and terms files in ~/terms, unless you choose another folder.
  2. Run. The first time you run a tool on each visit, Python starts in your browser, which takes a few seconds. The very first time, it also downloads about 10 MB. If a file would be overwritten, you're asked first.
  3. The result. You'll see Done, or the error if something went wrong, then what the program printed and the files it wrote. Each file has buttons to open it in the Studio, look at it, check it, pass it to another tool or download it.
  4. The same in the terminal, and in Python shows the command and the code, with buttons to run them in the Terminal tab or add them to a notebook.

More about this tool, under the title, explains what the tool does and doesn't do, and links to its page in this help. At the top right, the Python pill shows whether Python is running. Click it to see the versions of the packages.

The tools

Convert

  • Drawing → GA4GH Pedigree and Phenopackets (studio2ga4gh)
  • GA4GH or Phenopackets → drawing (ga4gh2studio)
  • Drawing → PED or MPED (studio2ped)
  • PED or MPED → drawing (ped2studio)
  • GA4GH Pedigree ⇄ Phenopackets Family (phenotk)
  • GA4GH → PED, table or YAML (phenotk)

Ontology terms

  • Match conditions to terms (hponorm and mondonorm)
  • Fill in missing terms (phenotk)

Check and look inside

  • Check against the standard (pedigree-ga4gh)
  • Upgrade a file from an older tool (pedigree-ga4gh)
  • Look inside a GA4GH file (phenotk)
  • Compare two files (phenotk)

Prepare to share

  • De-identify (phenotk)
  • Keep some people or terms (phenotk)
  • One file for each person (phenotk)
  • Put files together (phenotk)
  • Add findings to people (phenotk)

PED and MPED files

  • Summary and check, Take one condition out, Put PED files together, One file for each family, PED ⇄ MPED (mpedtools)
What the tab does not do

Each tool runs a package's own command, exactly as the package provides it, and the tab adds no conversions of its own. Match conditions to terms works differently, because it has no command. Instead, it searches using the packages' Python code and writes a terms file. A few commands have options that the forms leave out, such as the options for variants in phenotk add. In the terminal, man and --help describe them.
